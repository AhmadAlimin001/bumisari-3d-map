BUMISARI 3D MAP — VERSI ALTERNATIF GRATIS
=========================================
Teknologi: MapLibre GL JS + OpenFreeMap + data OpenStreetMap.
Tidak memerlukan Google Maps API Key atau billing Google Cloud.

PENTING:
- Peta memerlukan koneksi internet.
- Bangunan 3D hanya tampil jika footprint/data bangunan tersedia di OpenStreetMap.
- Peta dasar disediakan OpenFreeMap; data peta © OpenStreetMap contributors.
- Layanan publik OpenFreeMap gratis, tetapi tidak memberikan SLA/jaminan uptime.
- Ini belum merupakan model fotorealistis atau pemetaan lengkap Desa Bumisari.

CARA MEMPERBARUI WEBSITE GITHUB PAGES:
1. Ekstrak ZIP ini.
2. Buka repository GitHub bumisari-3d-map.
3. Tambahkan file index.html, manifest.webmanifest, sw.js, icon.svg,
   icon-192.png, icon-512.png ke root repository.
4. Jika ditanya, pilih Replace/Ganti untuk file yang namanya sama.
5. Commit changes.
6. Tunggu GitHub Pages selesai menerbitkan perubahan.
7. Buka kembali URL website dan lakukan hard refresh (Ctrl+F5).

PENGGUNAAN:
- Scroll untuk zoom.
- Drag mouse untuk menggeser.
- Klik kanan + drag untuk mengubah sudut pandang.
- Pada layar sentuh gunakan gerakan dua jari.
- Tombol pada panel mengatur sudut pandang dan posisi awal.

Atribusi peta ditampilkan melalui kontrol atribusi pada peta.
